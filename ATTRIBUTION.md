## Why this file exists

The ISC License requires the copyright notice and the permission notice to
appear in all copies. This repository redistributes upstream content, so both
license texts travel with every copy:

- `LICENSE-UPSTREAM` — verbatim upstream license, kept in the repository root.
- `skill/references/NOTICE.md` — same attribution, placed inside the shipped
  skill so it survives when the skill is packaged and installed alone.
- `NOTICE` — summary of what is authored here and what is copied.

## Relationship

This is a port, not a GitHub fork. The repository tree shares almost nothing
with the plugin: upstream carries 1800+ files of auditor reports and workflow
data, while this project ships one skill. A fork would carry that unrelated
history and be permanently labelled a fork. Attribution is carried here, in
`NOTICE`, in `README.md`, in `CITATION.cff` and in the shipped skill instead.

The upstream author has not reviewed or approved this port.
